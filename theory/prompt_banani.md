# Полный UI/UX дизайн для карточной игры «Шнопс» (Schnapsen/66)

## Общая информация о проекте

Создай **завершённый дизайн-систему и все экраны** для веб-приложения карточной игры «Шнопс» (66) на двух игроков. Игра — классическая австрийская карточная игра с колодой 24 карты (9, J, Q, K, 10, A четырёх мастей).

**Платформа:** Веб-приложение (десктоп-первый подход, адаптивность приветствуется)
**Инструмент:** Figma
**Стиль:** Современный, минималистичный, но с лёгкими элементами традиционной карточной эстетики. Тёмная тема по умолчанию с акцентом на читаемость и быстрое восприятие игрового состояния.

## Design System (обязательно создай первым фреймом)

### 1. Цветовая палитра

- **Primary:** Основной акцентный цвет для кнопок, активных элементов
- **Background:** Тёмный фон (#1a1a1a или близкий)
- **Surface:** Карточки, панели (#252525)
- **Suit colors:**
  - Spades (♠): чёрный/тёмно-серый
  - Hearts (♥): красный (#e53935)
  - Diamonds (♦): красный (#e53935)
  - Clubs (♣): чёрный/тёмно-серый
- **Trump indicator:** Золотой/янтарный (#ffa726) — для обозначения козыря
- **Success:** Зелёный (#4caf50) — подтверждения, победа
- **Warning:** Жёлтый (#ffb300) — таймеры, предупреждения
- **Error:** Красный (#d32f2f) — ошибки, проигрыш
- **Text:** Белый (#ffffff), серый (#b0b0b0) для вторичного текста

### 2. Типографика

- **Primary font:** Inter или Roboto (читаемый, современный sans-serif)
- **Headings:** 24px (h1), 20px (h2), 16px (h3), bold
- **Body:** 14px, regular
- **Caption:** 12px для подсказок, мелких данных
- **Card rank/suit:** Крупный, жирный шрифт для номиналов на картах

### 3. Компоненты

#### Карты (главный визуальный элемент)

- **Размер:** 80x120px (стандартное соотношение игральной карты)
- **Дизайн:**
  - Белый фон для открытых карт
  - Тёмная рубашка с паттерном для закрытых карт
  - Номинал (9, J, Q, K, 10, A) крупно сверху слева и снизу справа (перевёрнуто)
  - Масть рядом с номиналом
  - Центральная иллюстрация масти (упрощённая)
  - Тонкая обводка
  - **Hover state:** лёгкая тень, поднятие на 4px
  - **Selected state:** жёлтая обводка 2px
  - **Disabled state:** opacity 0.5

#### Кнопки

- **Primary button:** Заливка Primary цветом, белый текст, rounded 8px, padding 12px 24px
- **Secondary button:** Обводка, прозрачный фон, hover с заливкой
- **Icon button:** Квадратная, только иконка, 40x40px
- **States:** default, hover (brightness +10%), active (scale 0.98), disabled (opacity 0.4)

#### Input fields

- **Text input:** Тёмный фон Surface, обводка 1px (#444), rounded 4px, padding 10px 12px
- **Focus state:** Primary цвет обводки, glow
- **Error state:** Красная обводка, сообщение об ошибке снизу красным 12px

#### Modals/Dialogs

- **Overlay:** rgba(0,0,0,0.7) — затемнение фона
- **Modal:** Surface цвет, rounded 12px, padding 24px, max-width 480px
- **Header:** 20px bold
- **Actions:** Кнопки справа внизу (Cancel, Confirm)

#### Notifications/Toasts

- Появляются сверху справа
- Success: зелёный фон, белый текст, иконка галочки
- Error: красный фон, белый текст, иконка крестика
- Info: синий фон
- Auto-dismiss через 4 секунды

#### Timers

- Круговой прогресс-бар вокруг аватара игрока
- Цвет: зелёный → жёлтый → красный по мере истечения времени
- Цифры внутри (секунды)

- **Список открытых игр:**

  - «+ Создать игру» (большая primary button внизу или сверху справа)

### 5. Игровой экран — Основная игра (Game Screen)

**Это самый важный экран — детальная проработка!**

#### Раскладка:
```
┌─────────────────────────────────────────────┐
│  [Соперник: Имя] [Счёт: 0]  [Таймер: 30]   │ ← Верхняя панель
│  [Карты соперника: 6 закрытых карт]         │
├─────────────────────────────────────────────┤
│                                             │
│       [Игровое поле / Взятка]               │ ← Центр
│  [Карта 1 игрока]  [Карта 2 соперника]     │
│                                             │
│  [Козырь: ♥]  [Колода: 10 карт]            │
├─────────────────────────────────────────────┤
│  [Карты на руках: 6 открытых карт]          │ ← Низ экрана
│  [Я: Имя] [Счёт: 0] [Таймер: 30]           │
│  [Кнопки: «Марьяж» «Шнапс!» «Выйти»]       │
└─────────────────────────────────────────────┘
```

#### Детальные элементы:

**Верхняя панель (Соперник):**
- Имя + аватар слева
- Счёт очков раунда крупно: «Счёт: 0» (обновляется)
- Таймер справа: круговой прогресс-бар вокруг цифр (только когда ход соперника)
- Карты соперника: 6 карт рубашкой вверх, горизонтально выложены

**Центральная зона (Игровое поле):**
- **Текущая взятка:**
  - Слот для карты игрока 1 (слева)
  - Слот для карты игрока 2 (справа)
  - Когда карты сыграны — показываются открытыми
  - Анимация: карта вылетает из руки в слот
- **Информационное табло:**
  - «Ход: [Имя игрока]» — текст, подсвечивающий чей сейчас ход
  - Текущий козырь: крупная иконка масти + текст «Козырь: ♥»
  - Колода: стопка карт рубашкой вверх, сверху число оставшихся карт («10»)
  - Если колода пуста — зачёркнутая иконка или «Колода пуста»

**Нижняя панель (Вы):**
- Карты на руках: 6 карт открытых, горизонтально
- **Hover на карту:** поднимается вверх на 10px, появляется тень
- **Клик:** карта подсвечивается (жёлтая обводка), становится выбранной
- Имя + аватар слева
- Счёт очков справа
- Таймер вокруг аватара (когда ваш ход)
- **Кнопки действий:**
  - «Сыграть карту» (primary, активна только если карта выбрана)
  - «Объявить марьяж» (secondary, активна если есть K+Q одной масти на руках и колода не пуста)
  - «Шнапс!» (warning/золотая кнопка, активна если ≥66 очков после взятой взятки)
  - «Выйти из игры» (icon button, иконка exit)

**Состояния кнопок:**
- Неактивные кнопки: disabled state (opacity 0.4)
- Hover: лёгкая анимация

**Дополнительные визуальные фишки:**
- **Марьяж:** Когда объявлен марьяж, показать всплывающее уведомление: «Марьяж! +20 очков» (или +40 если козырный) — золотая анимация конфетти
- **Новый козырь:** После марьяжа — плавное изменение иконки козыря с анимацией
- **Взятие взятки:** Карты взятки «уезжают» к победителю с анимацией, очки обновляются с плавным счётчиком (number increment animation)
- **Добор карт:** После взятки карты плавно появляются в руке игроков (fade in + slide)

## Дополнительные фишки и детали

### Анимации (опиши в комментариях к фреймам)

1. **Раздача карт:** Карты вылетают из колоды к игрокам (по одной) с задержкой 0.1с
2. **Ход игрока:** Карта плавно перемещается из руки в центр взятки
3. **Взятие взятки:** Карты «едут» к победителю, затем исчезают (fade out)
4. **Добор карт:** Новые карты появляются в руке (fade in + slide from deck)
5. **Смена козыря:** Иконка козыря плавно меняется (cross-fade)
6. **Таймер:** Круговой прогресс-бар уменьшается плавно, в последние 10 секунд меняет цвет на красный и пульсирует
7. **Счётчик очков:** При обновлении счёта — анимация increment (число плавно растёт)

### Responsive (опционально, но желательно)

- **Мобильная версия (360x740px):**
  - Карты меньше (60x90px)
  - Вертикальная раскладка: соперник сверху, центр, вы снизу
  - Кнопки действий — bottom sheet или floating action button

### Accessibility

- Высокая контрастность текста на фоне
- Иконки масти дублируются текстом для дальтоников (можно toggle в настройках)
- Все кнопки и карты — крупные touch targets (минимум 44x44px)

## Технические требования к Figma-файлу

### Структура фреймов:

1. **Design System** (отдельная страница)
   - Цвета (палитра)

   - Иконки (масти, UI-иконки)

   - Все 11 экранов выше как отдельные фреймы
   - Desktop: 1280x720px
   - Mobile (опционально): 360x740px
3. **Flows** (опционально)
   - Прототипирование переходов между экранами

### Компоненты Figma:

- Создай **переиспользуемые компоненты:**
  - Card (игральная карта) с вариантами: открыта/закрыта, выбрана/не выбрана, каждая масть и номинал

  - Input field
  - Modal wrapper
  - Player info card (имя + аватар + счёт + таймер)
  - Toast notification
- **Auto Layout** для всех интерфейсных блоков
- **Variants** для состояний компонентов

### Иконки:

- Масти: ♠ ♥ ♦ ♣ (SVG или иконочный шрифт)
- UI-иконки: logout, exit, settings, clock, trophy, cards, user

### Экспорт:

- Все иконки и карты — экспортируемые как SVG
- Основные компоненты — доступны в библиотеке компонентов
